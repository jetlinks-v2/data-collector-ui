# 采集工作区

资源中心的采集器入口将连接配置、点位管理、实时数据和诊断放在同一个工作区。默认面向运维巡检，同时支持实施人员连续配置。

## 布局与操作

- 总览使用宽卡片，直接呈现当前异常、采集与输出数量、耗时和周期；点击进入采集器，返回后恢复列表位置。
- 左侧按通道或空间组织对象，名称下显示状态与重点指标。折叠与窄屏共用左侧抽屉。
- 点位支持卡片、表格、搜索、稳定排序、跨页选择及批量操作。显示数据不驱动持续重排。
- 点位名称下弱化展示标识和插件返回的地址；标识在同一采集器内唯一。
- 选中点位后，宽屏在右侧编辑，窄屏在当前卡片下展开。关闭详情可恢复列表宽度，未应用草稿保留。
- 新建先选择插件，再在工作区完成连接与采集参数；复用已有通道，不经过旧版多步表单。
- 主题、控件和字号沿用平台。状态、诊断和少量重点数字靠近名称；详细说明与完整指标按需展开。

## 插件与配置

协议配置继续使用插件 Vue 及现有注入、校验和联动契约；前端不尝试只凭 metadata 重建协议表单。`RenderComponents` 提供公共配置选择器和点位扫描工作区，并负责相对资源、样式及插件语言加载。

插件通过点位 metadata 声明地址、数据类型、自动解码能力和允许的 codec。平台只显示这些能力，不猜测协议字段，也不按 provider 标识分支。自动解码的点位不显示平台原始字节解码配置；平台解码时按有效字节长度筛选数据类型和字节布局。

数据处理沿用属性预处理习惯：清洗动作在前，可切换保留或限幅；转换可使用简单计算或结构化公式；随后配置变化判断、死区和结果处理。公式返回 null 表示忽略，0 和 false 保持有效。读写转换、旧范围与倍率配置保留服务端语义，不静默迁移。公共公式编辑器由共享模块提供。

数组用紧凑数值块、布尔色块展示，溢出横向滚动，按需展开虚拟列表。数值精度保留原始字符串；原始字节和位分布仅在有真实字节数据时提供。

## 实时数据与诊断

工作区使用 POST NDJSON 接口，首次返回当前快照，后续按订阅间隔更新。概览集中订阅当前采集器和通道；详情只订阅可见点位。切换范围、暂停或离开时释放订阅，旧请求不得覆盖新范围。批量目标从服务端查询获取，不把当前页冒充全部结果。

当前故障、历史故障与运行生命周期分开表达。当前失败显示红色，成功后清除当前故障并保留最近失败供诊断；保护状态分别显示降频重试、熔断和恢复探测。旧接口缺字段时保留未知，不能根据历史失败推断当前健康。

诊断入口在状态附近，展开单一时间线，展示执行步骤、相对时间、耗时和公共错误原因。时间轴共享时间刻度；父步骤耗时包含子步骤。回放优先定位最近失败，可选择当前可用的执行记录。

## 指标语义与性能边界

- 采集尝试、成功接收、过滤和对外输出分开统计；过滤不等于采集失败。
- 定时点位优先显示设置周期、相邻成功结果的实际间隔和距上次成功的时长。手动读取、订阅和备用实例不参与定时周期对比。
- 高频场景以同实例相邻快照的计数增量显示吞吐；低频场景以累计数量、等待状态和新鲜度表达。覆盖足够设置周期后才显示采集量对比，它不是精确按期率。
- 指标名称、单位、计数器、耗时、时间戳和分布语义来自 core 元数据。时间和流量自动换算单位，不根据指标名称猜测语义。
- 详情按语义分组，计数器显示总量与速率，耗时和瞬时值显示短趋势，分布显示桶边界。每项最多缓存30个采样点，关闭即释放。
- 无样本、统计中、等待更新、不可用与真实0分开表示。失败时保留最后有效值并提示时间，不绘制虚构趋势。
- 实例重建、计数回退、节点离线或采集归属改变时重置增量与趋势基线。集群汇总基于当前运行快照，不频繁写数据库。
- 复用集中采样与可见范围，不新增逐卡定时器、全量点位订阅或后台历史存储。页面短趋势仅代表查看期间的数据。

## 部署依赖

前端属于 `runtime-ui/modules/data-collector-ui`；运行快照、保护状态、诊断、指标元数据及 NDJSON 接口由 `collector-manager` 和 `collector-component` 提供。接口或插件不可用时显示明确错误，不能用模拟指标替代生产结果。语言资源覆盖简中、繁中、英、日、韩，插件文案按平台语言加载并回退。
