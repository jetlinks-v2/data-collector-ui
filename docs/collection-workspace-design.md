# 采集工作区

## 配置查找与批量编辑

查找、批量录入、核对修正、确认保存与返回定位共用现有工作区和本地草稿契约。owner 为 data-collector-ui，复用现有权限查询、插件批量列、地址生成和虚拟列表，不新增后端接口。

1. 点位定位：提供跨采集器的名称、标识及 ID 查找，显示所属采集器；选择结果后进入正确采集器并滚动定位。当前采集器的地址搜索继续使用插件返回的地址，不在平台解析协议地址。查询使用既有分页接口，限制候选数量、控频并隔离过期响应，不一次加载全部点位配置。导航继续经过草稿保护。
2. 批量查找与核对：表格上方提供名称／标识／地址的直接搜索，以及全部、已修改、待修正的数量入口；明确当前编辑的是全部、筛选结果还是所选点位。错误入口定位到具体行和字段；过滤不丢草稿，保存仍覆盖所有已修改行。
3. 表格与录入：提供通用列显示选择，固定身份与选择列，按实际显示列处理键盘和无表头粘贴；隐藏列不清除配置。范围添加允许沿用一条已选点位的配置并批量编号名称／标识，加入草稿前可核对示例。协议地址、数量、步长与字段联动仍由插件负责。
4. 完成反馈：新增、范围、粘贴和导入后定位到新增区域；校验及保存失败保留输入并定位问题，成功后保留当前查询和列表位置。所有修改确认后才调用已有保存／删除接口，保持三方合并与部分失败重试。

跨采集器查找入口放在“更多”中，以“查找所有采集器中的点位”说明范围；列表搜索只筛选当前范围，不再在标题区并列放两个搜索入口。`useWorkspacePointLookup` 使用 250ms 输入等待、请求取消和版本隔离，每次最多显示 20 条候选；过多结果提示补充关键词。导航沿用路由与草稿保护，弹窗关闭动画结束后调用 `PointCollection.reveal`，将虚拟列表中的目标挂载、滚动并聚焦。取消查找返回可见的“更多”按钮。

`usePointBatchEditor` 持有全部草稿与显示条件，`PointBatchQuery` 提供搜索、已修改／待修正数量和列选择；这些条件不缩小保存范围。身份列固定，隐藏列仅影响显示、键盘和无表头粘贴顺序；带表头粘贴与文件导入仍识别所有声明列。问题入口必要时清除显示条件、显示错误列并聚焦字段；无法归属字段的整体冲突保留行级反馈。列选择在当前工作区会话中保留，不另建偏好存储。

`PointBatchRange` 在仅选择一条可用点位时默认沿用其配置，平台只复制采集、处理、访问方式与保护等配置，不复制身份、归属或运行数据。地址生成参数继续交给插件；名称／标识前缀和起始编号由平台处理，保留如 `001` 的补零，加入前最多预览三条。失败保留输入；新增、粘贴、范围和导入后定位到新增区域。退出批量编辑按点位身份和行内偏移恢复原列表位置。

边界：不改变已有采集配置、实时订阅和权限契约；不引入协议名分支、全量元数据请求或第二套草稿存储。跨采集器查找遵循既有接口的数据权限；真实保存验收只使用本轮明确创建的测试数据。

验证（2026-11-19）：批量草稿、真实 Ant 控件、查询竞态与导航等 98 项回归通过，数采模块生产构建通过，五种语言 JSON 与 `git diff --check` 通过。12,000 行单测确认虚拟窗口有界；内置浏览器在 847px 与 1508px 宽度验证了跨采集器查找、1,000 行范围生成及草稿恢复（只挂载 25 行）、直接粘贴、错误字段定位、隐藏行保存和退出后的滚动位置恢复。临时千行草稿已移除；仅保存两个 `UX_PASTE_20261119_` 测试点位，所属通道继续禁用。

类型检查尚不能全量通过：宿主及原有代码存在类型错误，聚焦检查中余下五项位于 `api/data-collect/collector.ts`、旧的 WebSocket 请求入参和 `PointBatchColumnFilter.vue`，本次新增实现未报错。模块没有独立 lint 脚本；未逐一连接全部协议硬件，也未重新执行采集吞吐压测，本轮验证针对配置管理链路。

## 浏览范围与路由

### 层级、返回与批量模式

进入点位后可明确返回原采集器列表，右侧标题标明当前浏览的对象类型，批量编辑复用顶部第二行。owner 为 `runtime-ui/modules/data-collector-ui`，返回与编辑继续使用同一草稿保护。

**导航与内容层级**

- 左侧切换改为“按采集器／按通道”，表达导航的组织方式；保持既有单层条目和选中态。右侧用有名称的内容标题表达当前列表，不依靠搜索占位、数量单位或图标推断。
- 主区第一行表达浏览路径、当前对象、状态与对象动作，第二行表达当前内容及其查询／编辑模式；复用现有两行，不增加常驻第三行。

| 浏览范围 | 第一行：位置与对象 | 第二行：当前内容 |
| --- | --- | --- |
| 全部范围 | 全部采集器；新建采集等动作 | 采集器 · 数量；搜索采集器、筛选、排序 |
| 通道范围 | 全部采集器 / 通道名称；通道状态、连接设置 | 采集器 · 数量；搜索采集器、筛选、排序 |
| 采集器范围 | 原采集器列表 / 当前采集器名称；采集器状态、设置和点位动作 | 点位 · 数量；搜索点位、筛选、排序、视图等 |
| 点位批量编辑 | 保留同一浏览路径与采集器身份 | 点位批量编辑 · 编辑范围及数量；本地草稿、退出编辑 |

通道进入采集器后，上级路径保留对应通道名称，点击返回该通道的采集器列表；从全部范围进入则返回全部采集器。宽度足够时显示完整路径，窄容器收敛为具名的“返回采集器列表”入口和当前对象，长名称省略并提供完整提示；左侧收起后仍能返回。点位原位编辑继续留在当前采集器范围，关闭编辑回到点位列表，不增加新的点位详情路由。

**返回与状态契约**

- 复用 `hook/useWorkspaceRoute.ts`、`collectScopeRoute.ts` 的 `all/channel/collector` 范围及现有 URL。进入采集器时记录来源范围，返回通过明确的范围导航，避免直接链接或浏览器历史把用户带到工作区之外。
- 返回恢复来源列表的搜索、筛选、排序和滚动位置。刷新／直接打开采集器链接而没有来源时，优先回到它所属通道的采集器列表；无可用通道时回全部采集器。
- 返回、路径跳转及浏览器前进／后退使用同一草稿保护和保存期间禁止离开的规则；保留批量草稿，不新建持久存储或平行导航状态框架。

**批量编辑布局**

当前 1114×985 页面中，`.cw-main-controls` 与导航控件共用 100px 高度，而批量模式隐藏普通工具栏后，`.cw-controls-content` 实际仅 49px。空白来自两侧高度同步及缺失的第二行内容。

将 `PointBatchEditor.vue` 现有的编辑范围、本地草稿和退出编辑行移到主区第二行，由同一批量控制器提供状态与退出行为；正文从新增行、范围添加、粘贴、导入等实际操作开始，随后为查询和表格。移除正文重复标题，保留底部保存全部及其范围语义。普通、多选、批量模式各自提供真实工具行内容，顶部高度由实际内容统一测量；不按采集器、点位数或截图宽度添加负边距／固定高度补丁。插件工具继续保持挂载。

**实现入口与验证**

1. 在 `useWorkspaceRoute.ts`、`useCollectionWorkspace.ts` 接入明确的来源范围与返回动作，补路由及草稿保护回归。
2. 调整 `index.vue`、`ObjectNavigation.vue` 的路径、内容类型标题和五种语言文案；将批量模式标题归入相同的第二行。
3. 调整 `PointBatchEditor.vue` 及 `workspace.less` 的标题归属与自然高度测量，核对既有调用方、插件实例和滚动恢复。
4. 阶段末集中验证通道→采集器→点位→返回、全部范围返回、直接链接、刷新、前进／后退、取消离开、保存中禁止离开，以及普通／多选／批量模式和宽窄屏。执行相关交互／路由回归、模块构建、类型检查、五语键集及差异检查；模块没有独立 lint 脚本，既有依赖类型错误和精度失败单独标明。

这部分交互不改变后端、API、权限、菜单、运营端 `ui/` 或批量保存契约。浏览器已覆盖通道与全部范围返回、原查询及滚动位置恢复、前进／后退，以及 840／1114／1309px 普通与批量模式；批量表体不再重复显示顶部标题，窄屏退出入口可操作。

工作区导航与主区使用公共 `ResponsiveSplitter`。导航面板默认从 272px 起，按类型切换标签在标准字号下的实际内容宽度适当增宽，最多 432px；允许在 232～432px 内手动调宽，主区至少预留 592px。语言、字体和容器变化后重新测量默认宽度，手动调整后的尺寸仍由公共分区保留，不按语言名称特调。两区的标题、工具与正文均保留左右各 16px 的内部留白，面板尺寸预算包含这 32px，避免搜索框与卡片紧贴中间竖线。空间不足时由组件转为临时抽屉。同一导航实例随布局移动，搜索、分组和滚动保留；选择对象后关闭临时抽屉，手动折叠偏好与自动适配分开。收放入口使用 `PanelCollapseButton`，调宽、拖动收放及取消遵循公共组件契约，不再由页面维护固定断点和导航 Teleport。

### 工具栏组织

工具栏按“当前对象、当前列表、已选点位”划清操作范围，搜索位置、常用动作与模式切换保持稳定。owner 为 `runtime-ui/modules/data-collector-ui`，主要落点为 `views/data-collect/index.vue`、`components/workspace/WorkspaceSearch.vue`、`PointBatchToolbar.vue`、`WorkspaceListControl.vue` 及 `workspace.less`。

对象身份与业务动作位于第一行，查询与显示控制位于第二行，默认结构为：

```text
对象行：采集器名称  状态  设置  通道⌄          添加点位  编辑全部  更多⌄
列表行：搜索点位  状态：全部⌄  42 个点位      多选  最新创建⌄  暂停  卡片/列表
```

| 分区 | 内容与交互 |
| --- | --- |
| 对象行左侧 | 名称为主，状态只显示一次；状态本身进入运行详情，不再叠加异常数量和图表图标。设置紧邻名称。“通道⌄”用低强调短文字，展开后显示完整名称、状态、跳转与连接设置，不常驻整组通道控件，也不只剩难辨认的图标。 |

| 列表行左侧 | 搜索固定从左侧开始，按其他工具占位后的剩余空间适配：可分配至少 180px 时直接展示输入框，否则使用浮动入口并回显关键词；两种形式共享查询、清空和 Enter 语义，切换时保留输入并恢复焦点。状态筛选紧邻搜索，结果数量随其后，不因关键词长度将搜索移到另一边。 |
| 列表行右侧 | 多选、排序、实时暂停和卡片／列表切换按组排列；排序显示当前规则，避免同时重复“排序”和规则长名称。暂停状态与当前视图持续可见。 |

目标：让用户能连续比较采集时间、真实数值和保存原因，减少控件分行与重复说明；同时修复联调发现的结构化值存储损失。本次为 L 级前后端收尾，前端 owner 为 `runtime-ui/modules/data-collector-ui`，存储 owner 为 `modules/collector-manager`。

## 点位批量编辑

采集器工作区顶部按范围显示“编辑全部／编辑筛选结果／编辑所选”及数量。未勾选时载入当前筛选范围的全部点位，包含屏幕外的点位；已勾选时只载入所选点位。既有本机草稿一并恢复，无点位时仍可新增。进入时收起单点编辑区，退出后恢复原视图、筛选和滚动位置。编辑中的行与实时数据流隔离，不因状态刷新重排或覆盖输入。

“新增行”和“导入文件”只加入本地草稿，按当前账号和采集器隔离；退出后可重新打开，刷新前保留最后一个正在输入的单元格。“填入所选”只改选中行，“保存全部”才提交全部已修改行，包括被筛选隐藏的行。账号未确认或本机存储写失败时直接显示保留风险，不把未保存到本机的草稿显示成可恢复状态。待新增、待修改、待修正按行计数，错误入口定位首个问题。草稿仅保存有修改的配置及冲突基线，不保存观测值。

表格固定名称／标识与选择列，其他列横向滚动；行高 36 px，只挂载可视行及少量缓冲，并且只有当前单元格挂编辑控件。Tab、Shift+Tab、Enter 按真实列顺序移动，Esc 还原当前格；焦点明确移出或点击外部时提交本地草稿，控件内部临时失焦不提前提交。只对明确选中的可见行应用批量设置；未输入不覆盖，显式清空仍经过对应列转换与校验，0 与 false 保持有效。“还原所选”读取最新配置并舍弃对应草稿，新行则从草稿移除，不删除数据库点位。

右侧固定行操作支持删除和撤销，选中后也可批量删除。新建行从草稿移除；已有点位保留删除标记、划线及待删除数量，关闭或刷新仍可恢复。仅“保存全部”并确认删除后调用既有批量删除接口，先删除再保存，允许复用被删除的标识；并发修改会阻止删除，失败时保留尚未完成的行，重试不重新创建已删除点位。删除按 100 行分组，不新增服务端专用接口。

工具栏使用平台小尺寸图标与短文本：新增行、范围、粘贴和导入文件为常用组；选中行后才出现填入所选、还原所选的上下文组，整组换行。窄内容区隐藏次要文字，保留悬浮说明；底部保存全部按钮保持完整可见。批量模式通过外层显隐隐藏页头点位操作组，插件工具保持挂载，退出后复用同一个实例、引用和 batchAdapter。

支持从 Excel 复制 TSV：有常见中英文表头时按含义匹配，无表头时从当前格依可见列顺序填入。保留前导零、空单元格、Unicode、双引号转义及引用内换行／Tab；无法匹配的列直接提示。数据类型显示名称通过共享类型目录转换为原始标识，周期可输入毫秒或秒。粘贴不触发保存。

“粘贴”直接读取剪贴板并填入当前格或所选起点，不再打开独立粘贴面板；读取权限不可用时提示在格内按 Ctrl/Cmd + V。“导入”打开本地文件对话框，按需加载工作区已使用的 ExcelJS 4.4 解析 `.xlsx`，CSV 复用同一引用单元格解析器。可选择工作表并预览，再加入同一草稿；没有调用后端导入保存。当前 CSV 要求 UTF-8，旧 `.xls` 不在首版支持范围。

插件通过既有 `point-actions.batch.columns` 提供字段列，沿用 `dataIndex`、`form.name`、`template.components/props/getValue/customRender`。插件自定义 Vue 直接进入当前格，仅接收当前值和只读行／采集器上下文；双事件只更新同一输入缓冲。布尔控件沿用 `template.check` 绑定 `checked` 并读取 `target.checked`，保留明确的 `false`。格提交、粘贴和批量填充共用 `handleChange(value,index,record)`：在行副本上同步转换、联动后设置字段；整行粘贴按声明列顺序处理，`handleOptions` 有界调用。`point-actions` 宿主复用 `collector-data` 提供当前采集器引用，切换采集器同步更新。平台不包含协议名分支，不解析协议地址，也不推测字段类型或占用。

无法转换的原始输入和格错误保留到本地草稿，不把字符串写入完整配置对象。已转换的局部配置允许逐格填写，纯 `adapter.validate` 只标记行错并阻止保存，不回滚其他已填写格。只有活动格挂载 `form.rules`；异步结果按行、列和编辑版本归属，保存全部等待未完成校验，过期结果不得覆盖新输入。修正完成后只清理过期本地校验提示，网络和保存失败继续保留。

平台类型和字节序仍是公共列，根据 `isAutoCodec` 区分设备原生解析，空表也根据采集器的新点模板判断；支持的类型只在激活当前行解析格时获取，类型目录共享，不为全表逐点请求。可选字段空值显示“未设置”，缺少标识显示“未填写标识”，需公共解析但未选类型显示“未选类型”，原生自动解码显示“自动解析”；不适用的字节布局显示“不适用”，适用但未指定时弱化显示“默认”。原始非法输入和错误提示优先。采集方式按实际值翻译，单点和批量共用 ConfigSelect 的 `kind="access"` 与 tagRender，缺候选的已选订阅可翻译和移除，不增加候选。动态 fieldNames.value 由一个字符串键泛型约束原始值类型，不做运行时转换。Modbus 的地址范围函数继续复用：`40001 + 10 个 Float32` 得到 `40001、40003……40019`，占用到 `40020`。未声明字段列的旧插件保留已有地址适配和公共字段路径。

| 插件 | 当前格内字段 | 公共解析 |
| --- | --- | --- |
| Modbus TCP／RTU | 地址、数量、写功能码、非标读写长度 | 位区原生解析；寄存器使用平台类型和字节序 |
| S7 | 区域／DB、地址、PLC 类型、字符串容量 | Char／WChar／String／WString 原生，其余按能力使用公共解析 |
| BACnet/IP | 对象类型、实例、属性、值类型、写优先级 | 原生解析 |
| OPC UA | NodeId、类型、数组、采样、队列、溢出策略 | 原生解析；默认自动识别类型 |

范围生成当前由 Modbus 提供。其他插件支持字段编辑及粘贴，不意味着现场对象或 NodeId 可以按地址递增生成。

列头用24 px的弱化筛选图标，每个插件字段独立文本筛选，公共类型／方式／周期使用现有候选及范围。筛选不删除草稿；全选、填充、还原与键盘只处理当前可见身份，多行粘贴按当次可见行快照填入，超出末尾只追加，隐藏行不被覆盖。保存仍包含所有已修改行，底部显示可见／总数和追加反馈。

保存前批量读取已修改行，并做基线、草稿、当前配置的三方合并：仅应用明确修改的叶子，保留其他操作的无关修改；同一字段冲突拒绝覆盖。每 100 行使用既有 PATCH 保存，核对 `SaveResult.total` 后才清对应草稿。新增点位保留宿主生成的稳定 ID，网络中断后的重试不会重复创建；失败块保留可重试。新标识及修改后的标识校验采集器内唯一；历史重复标识未被本次修改时，不阻止无关字段调整。

## 列表与详情操作

- 点位支持卡片、表格、搜索、运行状态筛选、稳定排序及批量操作。目录不分页，卡片与列表复用虚拟滚动；全选覆盖全部筛选结果，默认试读仅作用于可见点位，显式批量试读按200个一批执行。
- 运行状态与指标排序跟随统计帧更新，数值增量不参与重排；相同顺序不重新赋值。运行条件生效时，离屏点位每轮查询完成5秒后补取轻量状态索引，每批200个、并发2，不读取完整值。晚到查询不得覆盖查询期间已到达的实时状态。编辑、多选时保持当前顺序；暂停、隐藏或离开时停止定时刷新，滚动按可视身份保持位置。
- 查询工具栏按搜索、选择入口、排序与筛选分组，按实际内容宽度伸缩；窄处保留图标和当前筛选值，整组换行。标题与主操作各自保持完整，不在组内拆行。虚拟表格保持固定行高，间隔列集中展示周期和达成情况，其余信号在状态与监控列查看。
- 平时点击点位查看详情，进入“多选”后整卡或整行切换选择，顶部显示独立的批量操作条和已选数量。全选覆盖当前筛选结果；退出、切换查询或采集器时清空选择，实时数据更新保留选择。当前采集器的未应用点位草稿须先处理，其他采集器草稿不拦截本次批量操作；离开页面仍保护全部草稿。批量执行期间锁定选择，不因空选中项隐藏操作导致工具栏跳动。
- 左侧条目的名称和状态摘要都进入点位列表，右侧独立图表按钮查看监控，避免主操作被状态浮层截断。
- 点位名称下弱化展示标识和插件返回的地址；标识在同一采集器内唯一。
- 点位名称入口的键盘焦点仅以名称细下划线提示，卡片与表格共用；Esc收起后回焦入口，不用整块蓝框表达焦点，避免与编辑选中、多选状态混淆。
- 点位编辑保留最新值及右侧实时指标，复用当前数据流；试读进度和本次结果只在试读按钮旁更新，不替换最新值区域，不重建输入控件。较长结果在当前行截断，可通过已有数据气泡查看完整值。
- 选中点位后，卡片原位进入编辑态并向下悬浮展开；表格行从当前行旁展开。点位、采集器和通道编辑统一支持点击页面外层或 Esc 收起，保留未应用草稿；浮窗入口和浮窗内部交互不触发收起。下拉、日期、图标、公式等弹层先处理自身交互，保存期间保持编辑器。编辑层位于平台浮层基础层级下方，气泡、抽屉及遮罩沿用组件库层级，不被编辑卡片穿透。外部点击不夺走新目标的焦点。开合仅裁剪展开高度，身份区不参与整层合成动画。单点试读的加载和结果限定在其编辑器，列表试读独立展示进度，不因单点状态向工具栏插入内容。
- 新建先选择插件，再在工作区完成连接与采集参数；复用已有通道，不经过旧版多步表单。
- 主题、控件和字号沿用平台。点位卡片、表格和编辑态共用一个状态入口，悬浮显示指标概要与最近异常，点击打开完整运行详情；最近读取记录在详情中展开时才订阅，收起、关闭或卸载时释放。采集与输出数值只读展示，不重复提供诊断按钮。集群异常优先显示正在发生的故障，否则显示最近一次异常的原因与时间。
- 异常恢复由后端确认：连续正常至少一分钟且有后续成功执行后，`failureSettled` 清除历史异常对状态、悬浮概要及排序筛选的影响。完整详情仍可查看最近异常。新故障、熔断、不可用和停止状态优先于此标记；前端不通过浏览器时钟或本地缓存推测恢复。
- 窄内容区保留新增、搜索、筛选和多选等常用入口；试读、插件浏览与批量导入收进“更多”，复用同一个插件工具实例和权限按钮。点位状态入口支持悬浮、键盘聚焦和点击；不隐藏当前状态或重点数据。

插件通过点位 metadata 声明地址、数据类型、自动解码能力和允许的 codec。平台只显示这些能力，不猜测协议字段，也不按 provider 标识分支。自动解码的点位不显示平台原始字节解码配置；平台解码时按有效字节长度筛选数据类型和字节布局。

访问模式、定时读取周期及数据处理由平台统一承载，插件只提供协议特有字段，避免重复配置。OPC UA 的服务端采样周期和订阅推送间隔是不同层级的协议参数，不与平台定时读取周期合并。

数据处理按“清洗 → 换算 → 滤波与计算 → 输出条件”展示，保存与告警单列。清洗可选择范围、无效数值或时序异常检测；换算可使用简单计算或结构化公式；滤波与计算使用换算后的值，再判断变化、死区及输出条件。阶段说明和算法下拉提示阈值使用换算前还是换算后的单位。旧清洗配置仍按原口径展示在换算后、滤波前，打开编辑不改写配置；公式返回 null 表示忽略，0 和 false 保持有效。读写换算、旧范围与倍率配置保留服务端语义，不静默迁移。公共公式编辑器由共享模块提供。

点位卡片底行将更新间隔、输出占比和比例条同排，维持虚拟行高度。窄卡片省略比例条但保留百分比；悬浮或键盘聚焦可查看过滤、失败等明细，点击不会误开编辑。输出占比以已完成处理的数据为分母，不等同于按计划采集的达成率；低频样本不足时继续显示累计数量。

数组用紧凑数值块、布尔色块展示，溢出横向滚动，按需展开虚拟列表。数值精度保留原始字符串；空字符串显示 `∅`，与尚未收到数据区分。原始字节和位分布仅在有真实字节数据时提供。
卡片及表格的数值、数组色块均支持悬停／聚焦预览，点击固定，Esc 或外部点击关闭。数值与诊断共用固定视口位置及内部滚动逻辑，实时刷新不移动浮层；值预览复用已有数据流，切到字节／位时才临时订阅原始数据，关闭后释放。
原始数据加载中、请求失败或本次不含原始字节时，不显示未经确认的“0 B”；只有实际返回字节后才展示字节数量。

## 实时数据与诊断

### 原始报文精度

目标：WebSocket 与 NDJSON 在原始文本边界保留点位大整数和高精度小数，安全数值、时间戳、零值与布尔值保持现有类型。共享 `@jetlinks-web/core` 拥有解析扩展点和连接／reader 生命周期；运行时宿主提供现有 `parseJsonWithPrecision`，数采订阅／请求显式选择该策略。解析选项只保存在客户端，不进入后端订阅参数或持久化配置。

实现：共享库 `packages/core/src/websocket.ts` 为 `getWebSocket` 第四个客户端选项提供 `deserializer(text)`，按订阅登记选择原文解析器，随重连和微前端委托保留；解析失败取消所属主题并进入其错误回调。`packages/core/src/fetch.ts` 在响应拦截器前解析 NDJSON 原始行，`validateResponse` 在状态分发及 reader 获取前保留格式与错误提示校验，退订停止剩余缓冲行并释放 reader。`api/data-collect/workspace.ts` 显式接入；宿主 `src/utils/ndjson-precision.ts` 复用共享 reader，旧 `src/utils/json/collector.ts` 的 ID 正则已移除。后端序列化、协议字段和其他订阅的默认数字类型保持原契约。

验证（2026-11-24）：上游共享库源码及完整 ESM 构建产物回归 40/40，声明生成与公开 API 严格类型用例通过；数采配合该候选包全量 261/261，包含当前工作区真实原始帧及兄弟订阅、嵌套值；宿主 NDJSON／认证夹具 30/30，候选包集成构建通过。宿主聚焦类型检查仍报共享 `@jetlinks-web/types/src/global.ts` 的 `PropType` 重复声明，本次改动文件无类型诊断；没有独立模块 lint 脚本。测试使用 `JETLINKS_SHARED_CORE_ROOT` 指向构建后的候选包，Vite 联调通过临时配置解析到同一产物，未改安装目录中的依赖源码，不能将候选包验证描述为已发布版本验证。未连接真实后端或协议设备。

交付：[共享库 PR #62](https://github.com/jetlinks-v2/jetlinks-project-ui-cli/pull/62) 已合并至 `3.0`（merge `daef225c`），包含 patch changeset；当前 npm 最新仍为 `@jetlinks-web/core@2.3.8`，正式发布及宿主依赖／锁文件升级待执行。版本可用后再更新真实依赖并复跑默认环境。微前端必须升级真正持有连接的宿主，不能仅更新子应用。

工作区复用平台统一 WebSocket 连接，POST NDJSON 接口继续可用，两者首次均立即返回当前快照。采集器及通道摘要、可见点位、诊断记录分别持有业务订阅；滚动只替换点位订阅，打开诊断只调整诊断订阅，摘要与速率基线持续更新。摘要负责采集器和通道的完整指标，点位请求不重复读取这两类对象的指标。每一路独立处理错误、取消和迟到帧，页面暂停或离开时统一释放。

统计按订阅间隔更新；可见点位的数据值跟随集群数据事件独立推送，每100ms最多一批，每点位保留最新值。背压时跳过推送时钟，不累积待播放的历史值。数据帧只更新值，不重算指标、节点状态或速率基线；延迟到达的旧快照不覆盖新值。批量目标从服务端查询获取，不把当前页冒充全部结果。

高频值帧按ID就地更新点位的浅响应字段；目录数组、排序结果和虚拟行身份保持稳定。仅配置、范围或统计轮变化时替换相关对象，避免每100ms扫描和重建整份目录。每个订阅请求仅保存当前可见及选中点位的最新待刷新值，取消时清理。

列表、通道及插件目录并行加载后建立监控流，避免初始化时重复订阅和重置统计基线。瞬时速率需要两次快照，首帧先显示已有状态、最新值和可直接读取的指标，不伪造速率。

订阅点位首帧展示已有接收和输出总量，获得有效增量后切换为速率，避免把统计基线等待显示成数据仍在加载。点位编辑器复用详情响应中的协议元数据，仅在配置变化时重新解析，相同的插件通知合并为一次请求。

采集器卡片首帧同样展示已有的接收、输出、过滤和采集次数，不为等待速率而留空。从详情返回、切换范围或恢复订阅时，直接复用对象已持有的上一次节点快照计算增量；节点或实例变化、计数回退仍重新建立基线。该过程不增加快照缓存和额外请求。

侧栏状态与统计独立展示：文字状态始终靠左，采集／输出以淡色图标和数值置右，异常与保护状态不隐藏有效指标；真实零值保留，未取得的指标不补零。采集器使用执行图标表示发起采集次数，点位按接收或定时采集区分，数据输出使用出框箭头；通道流量使用成对收／发图标。侧栏和运行摘要面板共用同一份指标图标定义，面板保留完整名称并弱化图标。提示保留指标名称和准确口径，采集尝试不等同于成功接收。累计值与速率复用主区口径。运行摘要气泡沿用 Ant Design 原生面板和箭头，仅限制内容滚动，不添加描边、箭头阴影或偏移。

运行排序包括异常优先、最近耗时、接收间隔偏差和累计过滤量。启用这些排序或运行状态筛选时，先读取全目录的有限状态快照：每批最多200个点位，最多两个并发请求，仅投影8个相关指标，`includeData=false` 不读取最新值。点位索引和可见点位订阅均设置 `includeObjects=false`，不重复计算采集器／通道快照；旧调用省略此选项时保留对象快照。内存只保留状态、优先级和排序标量，不保留全目录的指标树。快照排序在滚动期间保持稳定，按钮提示快照时间，可就地更新；不能把单次累计量当作速率进行排序。

采集器与通道的诊断直接消费摘要目录中的持续快照，不依赖当前是否进入某个采集器，也不因点位滚动而重建。摘要尚未到达时可补读一次，收到摘要后取消补读；点位诊断继续消费可见点位观测。

实时快照尚未到达时，统一显示中性的“等待运行信息”，不使用目录中持久化的运行态推断当前健康；停用、暂停等明确管理状态仍直接展示。滚动释放离屏快照后遵循相同语义，收到完整快照后再显示运行中、异常或暂无运行数据，不为保持绿色状态保留离屏指标树。

点位最近记录在已有的有界采集器回放中按步骤归属投影，未标记的子步骤继承父步骤的点位；批量执行中的其他点位和采集器级合并摘要不计入当前点位。当前异常原因仍来自点位运行快照，没有采样步骤时明确显示暂无采样记录。该投影只在诊断打开、每秒收到回放时执行，不增加订阅、后端采样或逐点缓存。公共错误原因由状态、异常摘要和回放统一翻译，未知原因保留错误码供排查。

点位目录使用 `/point/directory/_query/no-paging`，只返回名称、标识、插件解析的地址、单位、周期及状态等列表字段，不携带完整配置和协议元数据。完整配置仅在选择编辑点位后查询，切换时取消过期请求，内存只保留当前点位配置与未应用草稿。指标定义继续按类型和语言共享，隐藏的编辑器、诊断与完整指标面板按需加载。

详细流由实际可见点位和当前选中点位驱动，排除虚拟滚动缓冲行；首批可见范围立即订阅，后续变化立即取消旧流，停留120ms后才订阅新范围，释放移出范围的值与指标。空结果保留采集器健康监控，首次挂载非空列表不先发空点位请求。集群节点状态统一汇总，单个节点故障不会被健康副本掩盖。观测到点位样本的匹配按ID建立映射，避免全目录逐点扫描节点样本。

导航参考 [Kepware 的通信与点位层级](https://support.ptc.com/help/kepware/drivers/en/kepware/drivers/CONTROLLOGIXETHERNET/tag-hierarchy.html) 和 [Ignition Tag Browser 的文件夹与设备浏览](https://www.docs.inductiveautomation.com/docs/8.1/platform/tags/tag-browser)。通信结构用于定位连接故障，业务空间用于按现场对象查找；默认平铺是本工作区对少量采集器巡检的交互选择，并非行业标准的强制要求。

当前故障、历史故障与运行生命周期分开表达。当前失败显示红色，成功后清除当前故障并保留最近失败供诊断；保护状态分别显示降频重试、熔断和恢复探测。旧接口缺字段时保留未知，不能根据历史失败推断当前健康。

页头诊断使用标准 FileSearchOutlined 图标，点位状态附近保留快捷入口。展开单一时间线，展示执行步骤、相对时间、耗时和公共错误原因。时间轴共享时间刻度；父步骤耗时包含子步骤。回放优先定位最近失败，可选择当前可用的执行记录。
诊断浮层打开时确定视口位置，刷新内容不重新翻转；高度受窗口约束，完整内容在面板内滚动。排序和筛选分别标明用途及当前选择，运行状态筛选启用时强化颜色。
回放连接中断时保留已取得的状态、指标和回放，提示连接中断；后续状态更新触发重连，收到新回放即清除旧错误。健康连接不重复订阅，关闭面板、暂停或页面隐藏时停止连接。

运行诊断使用内存指标及有界采集记录，不再为每条成功、过滤或失败结果写入 `collector_point_log`，也不在该链路构造日志、原始字节十六进制或异常堆栈。业务历史仍由点位的正常数据、异常值和死区存储开关分别控制；旧日志接口只查询已有历史，不能用当前内存计数冒充历史时间桶。

## 指标语义与性能边界

- 采集尝试、成功接收、过滤和对外输出分开统计；过滤不等于采集失败。
- 定时点位优先显示设置周期、相邻成功结果的实际间隔和距上次成功的时长。手动读取、订阅和备用实例不参与定时周期对比。
- “读取间断”沿用后端汇总：曾成功读取的定时点位超过两个设置周期未再次成功读取时计入。详情直接说明依据、排除范围和排查建议，摘要提供可聚焦的帮助气泡；不把它当作请求超时或清洗失败。
- 订阅点位显示平均更新间隔：使用同实例相邻统计轮之间的真实到达跨度与新增样本数计算，到达年龄校正窗口边界。批量送达不会把批内微秒间隔当作主更新节奏；无新样本保留上次平均值，并在悬浮说明中展示距上次接收的时长。实例变化时重新建立基线，原始相邻间隔保留在完整指标中。
- 高频场景以同实例相邻快照的计数增量显示吞吐；低频场景以累计数量、等待状态和新鲜度表达。覆盖足够设置周期后才显示采集量对比，它不是精确按期率。
- 指标名称、单位、计数器、耗时、时间戳和分布语义来自 core 元数据。时间和流量自动换算单位，不根据指标名称猜测语义。
- 详情按语义分组，计数器显示总量与速率，耗时和瞬时值显示短趋势，分布显示桶边界。每项最多缓存30个采样点，关闭即释放。
- 无样本、统计中、等待更新、不可用与真实0分开表示。失败时保留最后有效值并提示时间，不绘制虚构趋势。
- 实例重建、计数回退、节点离线或采集归属改变时重置增量与趋势基线。集群汇总基于当前运行快照，不频繁写数据库。
- 复用集中采样与可见范围，不新增逐卡定时器、全量点位订阅或后台历史存储。页面短趋势仅代表查看期间的数据。

## 部署依赖

前端属于 `runtime-ui/modules/data-collector-ui`；运行快照、保护状态、诊断、指标元数据及 NDJSON 接口由 `collector-manager` 和 `collector-component` 提供。接口或插件不可用时显示明确错误，不能用模拟指标替代生产结果。语言资源覆盖简中、繁中、英、日、韩，插件文案按平台语言加载并回退。

插件打包沿用各仓库的构建入口：Modbus／S7 使用普通 `package`，BACnet 使用 `-Pbacnet-plugin`，OPC UA 使用 `-Pfatjar`，确保包内包含运行依赖和配置脚本。
